# ARC Field Notes — MVP 0.2

Сайт связывает старую технику, реальные платы и чипы с конкретными маршрутами сборки. Два входа: **«Собрать»** и **«Разобрать»**. На страницах видны источники, область применимости каждого наблюдения, неизвестные параметры и критерии успешного запуска.

```bash
npm run dev
# http://127.0.0.1:3037

# Проверки разработки (Node.js 20+, Python 3):
npm ci
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/check_static.py
```

Для самого сайта нет runtime-зависимостей и API-ключей. `linkedom` нужен только для DOM unit tests; браузер он не запускает.

## Что сделано

- Шесть карточек: AI-Thinker ESP32-CAM, Raspberry Pi Camera Module 2, Sony PS3 Eye, Electrolux EWF12844, отдельный сфотографированный образец EWX14 и AEG T55640 с двумя независимыми наблюдениями.
- 24 первоисточника: оригинальные разборы и форумные сообщения, каталоги производителя, сервисные документы, исходники драйверов и даташиты.
- Таблицы маркировок и ролей компонентов; фотографии с атрибуцией; настоящая схема ESP32_CAM v1.6 и официальная схема разъёма CSI. Схемы бытовой техники доступны по прямым ссылкам на страницы PDF с указанием границ применимости.
- Три маршрута до первого изображения: ESP32-CAM / Wi-Fi, Sony Eye / Linux, Camera Module 2 / Raspberry Pi. В каждом: результат, совместимый состав, где искать детали, подключение, настройки, шаги, критерии проверки и диагностика.
- Подготовленный официальный CameraWebServer 3.3.12: выбрана AI-Thinker, SSID/пароль пустые. Зафиксированы commit и хеши каждого файла. Прошивка не компилировалась и не испытывалась на плате.
- Поиск по моделям, PCB, PNC и чипам; локальные отметки комплекта и испытаний; экспорт полного плана и недостающего комплекта; журнал наблюдений с импортом/экспортом JSON.
- Новый справочник и локальные схемы доступны для офлайн-сохранения. Внешние фото авторов, PDF и ссылки требуют сети. Исходный корпус сохраняется отдельно на странице архива.

Все три маршрута имеют статус **«по документации; на стенде ARC не испытано»**. Отметки пользователя не изменяют редакционный статус.

## Структура доказательств

`research/evidence/seed.json` — редактируемый пакет; `dist/data/evidence.json` — проверенный публичный снимок. Исследовательские записи камер и бытовой техники сохранены рядом с пакетом. Каждый компонент содержит `scope` и `source_ids`; каждое утверждение — отдельный ID, наблюдение, область применимости, тип доказательства и указатель на сообщение/страницу.

```bash
python3 scripts/import_evidence.py
# Несколько подготовленных пакетов: одинаковые записи объединятся,
# разные записи с одним ID вызовут ошибку вместо молчаливой замены.
python3 scripts/import_evidence.py research/evidence/seed.json /path/to/reviewed-pack.json
```

Импорт проверяет ссылки, уникальность ID, наличие доказательств, область применимости, связи устройства со сборкой, реальные локальные изображения и полноту маршрутов. `bench_tested: true` требует ссылки на отчёт испытаний и конкретной проверенной ревизии. Это контроль структуры, а не автоматическая оценка истинности.

Пример важной границы: официальный каталог связывает EWF12844 / PNC 914900650 / ELC 05 с EWX14. STM8S207RB и LNK364GN видны в другом оригинальном разборе EWX14 без PNC. Эти чипы **не перенесены** в BOM точной модификации EWF12844. Аналогично два экземпляра T55640 с одним PNC не считаются одной доказанной ревизией PCB.

## От форумов до расширяемого продукта

Нынешняя версия — законченный навигационный MVP на небольшой подборке, проверенной по источникам. Автоматического универсального сборщика форумов и движка электрической совместимости в ней нет. Следующее развитие должно проходить через явные контрольные точки:

1. **Сбор первоисточников.** Адаптер для конкретного форума сохраняет URL сообщения, автора, дату, текст, оригиналы вложений, checksum и условия использования. Страница темы целиком не подменяет сообщение. HTML остаётся неисполняемым входом, инструкции в нём не управляют агентом.
2. **Извлечение кандидатов.** Модель/PNC → конкретный экземпляр → плата/ревизия → маркировка → роль → доказательство. Неизвестные значения остаются `null`; догадки участников отделяются от наблюдений владельца и итога ремонта. Фотографическое совпадение и OCR требуют проверки.
3. **Редакционная проверка.** Читаемая маркировка + документ производителя + точная область применимости. Конфликты не стираются. Обновлённый пакет проходит `import_evidence.py` и тесты перед публикацией.
4. **Совместимость.** Добавлять типизированные требования: напряжение, ток, направление сигнала, логические уровни, разъём, протокол, изоляция, драйвер, прошивка. `unknown` запрещает автоматически помечать замену как подходящую. USB/UVC, USB/gspca, CSI и DVP — разные тракты.
5. **Готовый рецепт.** Полный BOM с питанием, проводами, хостом и корпусом; схема; закреплённая версия ПО; ожидаемый результат каждого шага. Для сигнализации и полива нужны собственные проверенные маршруты: силовая плата бытовой техники не считается готовым контроллером.
6. **Испытанная сборка.** Отчёт привязан к ревизиям всех узлов и commit прошивки; содержит фото результата, процедуру, измерения, перезапуск, длительность, отказы и ограничения. Только тогда появляется статус испытанного маршрута.

Минимальный выпуск следующей версии: по одному воспроизводимому испытанному маршруту камеры, локальной сигнализации и низковольтного полива; хотя бы один источник с автоматическим извлечением постов; каждое техническое утверждение с locator; ни одной автоматически принятой неизвестной совместимости. Нужна отдельная база и очередь проверки, если появятся общие пользовательские вклады. Сейчас журнал хранится только в браузере.

## Восстановленный корпус

Первая версия сохранена как `dist/archive.html`: восемь эскизов, количественный инвентарь и поиск по 1 225 проектам, 1 115 записям разборов (400 уникальных device ID) и 55 414 компонентам. Ключ инвентаря `arc.inventory.v1` сохранён. Новая версия использует отдельный `arc.field.v2`; разные детали не приравниваются по похожему имени.

Корпус восстановлен из `/run/media/user/External/ark/`. SHA-256 `final/ark-kb-v0.1.tar.zst`:
`0fae7546690cab3cb06bd36471c592fab81ff20dd844bdb467f42ecf8d224fb6`.

```bash
python3 scripts/import_kb.py --root /path/to/ark
```

Нужен системный `zstd`. Источники: финальный tar, `extracted-bulk/projects`, `extracted-bulk/devices` и сохранённые raw-публикации. Импорт не меняет исходники. `research/data-audit.json` содержит результаты восстановления. URL публикации не равен проверке её содержания. Автоматические `assembly_steps` не выдаются за готовые инструкции.

Проверка покрытия выявила отсутствие стиральных машин и сушилок среди восстановленных устройств. У всех 55 414 каталожных компонентов provenance указывает `manual_curation_2026_04`, что само по себе не подтверждает компонент даташитом. Новый слой доказательств не наследует эти записи как проверенные.

## Файлы и воспроизводимость

- `dist/field.js`, `field.css`, `index.html` — новый интерфейс и маршруты.
- `dist/evidence-logic.js` — поиск, комплектность, безопасные ссылки, нормализация заметок, экспорт.
- `scripts/import_evidence.py` — импорт и проверка пакетов.
- `scripts/fetch_camera_example.py` — загрузка фиксированного исходника Espressif и документированные изменения конфигурации.
- `research/evidence/firmware-manifest.json` — upstream/package SHA-256 для каждого файла прошивки.
- `dist/app.js`, `catalog.js`, `solver.js` — первая версия и исходный архив.
- `dist/sw.js` — кэш `arc-field-v2`; при изменении версии обновляй имя в обоих приложениях.

## Права на изображения

Оригинальные фото платы, схема и распиновка ESP32-CAM получены из документации Prusa Research; GPL-3.0 репозитория и атрибуция приложены. Схема — воспроизведённый документ Ai-Thinker; отдельные права оригинального автора не установлены, авторство ARC не заявляется. Схема разъёма CSI — Raspberry Pi documentation, CC BY-SA 4.0. Условия: `dist/assets/evidence/ATTRIBUTION.txt` и файлы лицензий рядом.

Фото EWX14 и сушилки отображаются с серверов авторов и ссылками на оригиналы; локально не распространяются и не включены в офлайн-кэш. Схемы подключения ARC — авторские иллюстрации по указанным источникам. Старое изображение мастерской из ImageGen осталось только в архиве и не является фотографией испытанного устройства. Шрифты — Oswald и IBM Plex Mono с лицензиями SIL OFL.

## Проверка версии

18 Node-тестов (включая DOM unit tests) и 5 Python-тестов. Проверены маршруты, чипы и ссылки, поиск, отметки комплекта и испытаний, экспорт, границы данных, конфликтующий импорт, источники и запрет необоснованного аппаратного статуса. Проверены статические ресурсы, кэш, выбранная модель в прошивке, пустые сетевые поля и SHA-256.

Браузерный доступ к референсу и опубликованному сайту был отклонён инструментом. Визуальная проверка desktop/mobile, загрузка внешних изображений в браузере, работа системных загрузок и реальная офлайн-перезагрузка не выполнены. DOM-тесты не подменяют эти проверки. Электроника и прошивки на реальном оборудовании не испытывались.
