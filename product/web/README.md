# ARC Field Manual — MVP

Русскоязычный сайт для выбора полезных сборок из доступных деталей. Работает как статическое приложение: без API-ключей, внешних шрифтов и серверной базы.

```bash
npm run dev
# http://127.0.0.1:3037
npm test
python3 scripts/check_static.py
```

Зависимости для запуска: Python 3. Для тестов: Node.js 20+. Установка npm-пакетов не требуется.

## Возможности

- Восемь подробных стартовых маршрутов: камера Raspberry Pi, USB-наблюдение с Motion, сигнализация Arduino, фитильный и таймерный полив, USB-свет, вентилятор, локальный архив файлов.
- Инвентарь с количеством, сохранением в браузере и импортом/экспортом JSON.
- Подбор по точным идентификаторам и количеству; объединение повторных требований BOM.
- Спецификации, возможные доноры, контроль совместимости, планы и списки недостающего в TXT.
- Поиск по 1 225 проектам, 1 115 записям разборов (400 уникальных device ID) и 55 414 компонентам.
- У всех 1 225 проектов восстановлен URL исходной публикации из сырого корпуса. Это не проверка содержания публикации.
- Сохранение интерфейса и корпуса для офлайн-работы через Service Worker. Внешние ссылки требуют сети.

## Данные

Источник восстановления: `/run/media/user/External/ark/`.

- `final/ark-kb-v0.1.tar.zst` — компоненты, материалы, навыки, цели, инструменты, физические явления и региональные профили. Проверка SHA-256 выполнена.
- `extracted-bulk/projects/` — 1 225 проектов.
- `extracted-bulk/devices/` — 1 115 разборов с повторяющимися ID моделей. Навигация использует уникальное имя записи.
- `raw/instructables/`, `raw/hackaday/` — восстановленные ссылки и авторы.

Импорт воспроизводится командой:

```bash
python3 scripts/import_kb.py --root /path/to/ark
```

Нужен системный `zstd`. Скрипт читает архив потоком, проверяет контрольную сумму и создаёт компактные JSON в `dist/data/`. Исходные файлы не изменяются. Отчёт: `research/data-audit.json`.

В импортированном корпусе встречаются недостоверные технические утверждения. Исходные `assembly_steps` не включены в сайт. Каталоги `comp:` и `cmp:` имеют разные пространства идентификаторов: связи между ними не выдумываются. Полный BOM означает только совпадение состава; физическая работоспособность и безопасность требуют проверки. Стартовые планы не проходили аппаратных испытаний.

## Файлы

- `dist/catalog.js` — стартовые маршруты, спецификации и доноры.
- `dist/solver.js` — чистые функции инвентаря и подсчёта комплектности.
- `dist/app.js` — интерфейс, каталог, экспорт и локальное сохранение.
- `dist/sw.js` — офлайн-кэш. При обновлении статических файлов меняй версию CACHE и имя кэша в app.js вместе.
- `tests/solver.test.mjs` — семь проверок логики и целостности корпуса.
- `dist/assets/door-alarm.ino` — учебный пример Arduino с подавлением дребезга; физически не испытан.

## Дизайн и лицензии

Палитра полевой мастерской: графит, оливковый, состаренная бумага, сигнальный оранжевый. Технические иллюстрации сделаны в SVG. Обложка `dist/assets/workbench.webp` создана встроенным ImageGen, это концепт, а не фотография работающего устройства. Промпт сохранён в `research/image-prompt.txt`.

Шрифты ARC Display и ARC Mono — подмножества Oswald и IBM Plex Mono с переименованными внутренними семействами. Лицензии SIL OFL включены рядом с файлами. Код наследует Apache-2.0 проекта ARC; условия первоисточников корпуса сохраняются и могут отличаться от лицензии базы.

## Проверка версии

Проверены синтаксис JS, семь сценариев логики, количество записей, ссылки на локальные ресурсы и HTTP 200 локального сервера. Предпросмотр через Chrome был отклонён политикой доступа (инструмент сообщил отказ пользователя). Визуальная проверка desktop/mobile, реальные клики, загрузки через браузер и офлайн-перезагрузка не подтверждены. Адаптивные стили реализованы для экранов от 360 px.
