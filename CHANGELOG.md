# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-04-29

Initial public release.

### Added
- FastAPI server with vision identification endpoint.
- Knowledge-base loader with CDPO schema (12 entity categories).
- Reverse-BOM solver with constrained generation.
- htmx web UI.
- Validation pipeline (schema, cross-reference, anti-laziness, coverage).
- Packaging scripts producing compressed tar.zst artifact.
